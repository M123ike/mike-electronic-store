## 🚧 Challenges Faced

1. **Image sizing** – Product images had inconsistent dimensions; fixed by cropping all images to the same aspect ratio in Wix.
2. **Cart setup** – Wix required connecting a payment method to fully activate the cart; used the "Add to Cart" simulation button as a workaround.
3. **Mobile responsiveness** – Some sections required manual adjustment in Wix's mobile editor to display correctly on small screens.
4. **GitHub Markdown** – Learning to embed screenshots using relative paths in README.md was new but manageable.

---

## 📚 Lessons Learned

1. **No-code platforms are powerful** – Wix allowed me to build a fully functional e-commerce site without writing a single line of code.
2. **UX matters** – Navigation, color choices, and layout significantly affect how users experience a store.
3. **Documentation is as important as the product** – Writing a clear README.md helps others (and future me) understand the project quickly.
4. **GitHub is essential** – Version control and public documentation are key professional skills even for no-code projects.
5. **Planning before building saves time** – Sketching the page structure before starting in Wix made the build process much faster.
